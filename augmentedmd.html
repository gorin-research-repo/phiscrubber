About the Creator

Michael Gorin, MD

Academic urologist at Mount Sinai focusing on use of technologies (AI-based and conventional) to improve patient safety, operational efficiency, and physician effectiveness.

The integration of AI into healthcare offers extraordinary opportunities—but also unprecedented challenges around privacy, reliability, and workflow integration. These tools are designed to help clinicians harness these technologies responsibly and effectively.

Open Source

All tools on this site are open source and free for anyone to use or improve upon. The code is available on GitHub for those interested in contributing, forking, or learning from the implementation.
